# Changelog

## Current development snapshot — 2026-10-25
- Initial Rust standalone coding agent with bounded model/tool loop and scoped writes.
- Signed local policy and identity checks, audit journal, budgets, approval records and data governance.
- MCP signed delegation and source response verification with human-only final submission boundary.
- SQLite-backed attention/alert protocol, Mirror retrospective critique, and twelve native metadata tools.
- Source-backed Markdown claims audit and synthetic generator for fault catalogues.
- Structured documentation contracts, subsystem references and manifest-gated documentation checks introduced in this work.
## Release discipline
- This is a development summary, not proof that the entire feature set is production-ready.
- Record each tagged release with commit, migration implications, compatibility and security advisories; link evidence, not only test counts.
- Breaking contract changes need a version note and a migration or explicit refusal path.
## Known exclusions
